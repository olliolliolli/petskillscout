# PetSkillScout

Hunter companion addon for **WoW: Forever** (Interface 16001): teaching beasts for pet skills,
rare tameable beasts, your pet, gear advisor, hunter quests and quest ratings.

- `PetSkillScout/` — the addon (this folder goes to `World of Warcraft/_forever_/Interface/AddOns/`).
  Player readme and changelog: `PetSkillScout/README.txt`.
- `tools/` — tests, build script and the QuestDB generator (see `tools/README.md`).
